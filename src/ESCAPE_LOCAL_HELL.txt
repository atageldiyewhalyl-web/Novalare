## 🚀 Quick Deploy (3 Steps)

### STEP 1: Push to GitHub
```bash
cd novalare-extraction-api
git add .
git commit -m "Add AI extraction API"
git push origin main
```

### STEP 2: Create Render Service
1. Go to https://render.com (free account)
2. New + → Web Service
3. Connect GitHub → Select your repo
4. Configure:
   - Root Directory: `python-extraction-server`
   - Build: `pip install -r requirements.txt`
   - Start: `python app.py`
5. Add env var: `OPENAI_API_KEY = sk-proj-YOUR_KEY`
6. Click "Create"

### STEP 3: Test It
```bash
curl https://YOUR_URL.onrender.com/health
# Should return: {"status": "healthy"}
```

## 🚨 Common Issues & Solutions

→ Verify all dependencies listed

### Issue: Service won't start
→ Check `OPENAI_API_KEY` is set
→ Verify `PORT` environment variable

### Issue: OpenAI errors
→ Verify API key is valid
→ Check OpenAI usage limits
